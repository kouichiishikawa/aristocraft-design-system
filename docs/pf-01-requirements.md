# PF-01 公開要件・対象読者・稼働時間

- Notion タスク: https://app.notion.com/p/3d8c972c2bcb814994dde80721785aa3
- 計画ページ: https://app.notion.com/p/3d8c972c2bcb810caa4ffdf69afa97d9
- 状態: 確定（2026-09-11、本人判断）

## 1. 目的と優先順位

| 項目 | 決定 |
|---|---|
| 主目的 | デザインの依頼・協業が主。音楽活動紹介は従（サブコンテンツ） |
| 対象読者（優先順） | 1. 企業の採用担当・デザイン責任者 2. プロジェクト単位で依頼するクライアント・協業相手 3. デザイナーコミュニティ・同業者 |
| 対応言語 | 日本語・英語の完全二言語 |

Music セクションはプロフィール補強として扱い、Home では Works/About/Contact を優先する。

## 2. 公開必須ページ

- Home
- Works 一覧・詳細（代表事例 2 件を初期範囲）
- About（経歴・強み・価値観・働き方・音楽との関係・依頼導線）
- Music（プロフィール、公開可能な演奏メディア 1〜3 点、活動/依頼情報。サブ扱い）
- Contact
- 補助AI（任意で開く導線。通常閲覧は AI なしで完結）
- 既存 Blog: 棚卸し（PF-02）で移行 / 外部リンク / アーカイブを決定

すべて日英で用意する。

## 3. 日程と稼働

| 項目 | 決定 |
|---|---|
| 公開目標日 | **未定**。DS v1 完成後（2026-11 末）に再見積もりして決める |
| 週の稼働時間 | 5〜10 時間 |
| 期限の扱い | 伸ばしてよい。稼働と二言語化の工数に合わせて調整 |
| 費用上限 | 月 3,000 円以内（Figma・ドメイン・配信・AI API の合計）。無料枠中心 |
| 週次レビュー | 週 1 回 Claude Code で Notion Task DB の進捗を確認し、次の着手を決める |

### 計画からの変更点

- 計画の前提（日本語のみ・週 10 時間・2027-04-15 公開）から、二言語化と稼働減で工数が増えるため、公開日を未定に変更。
- 2026-09〜11 の Design System フェーズ（PF-07〜16）はスケジュールを維持する。12 月以降の PF-02〜40 は DS v1 完成時に日程を引き直す。
- 英語化は「別見積もり」だったものを初期公開範囲に含める。PF-08（書体・レイアウト規則）と PF-25（コンテンツモデル）は最初から二言語前提で設計する。

## 4. 成功指標

1. Design System が実際に機能すること（トークン → Figma → コード → AI の接続が再現できる）
2. 品質指標: p75 で LCP 2.5s / INP 200ms / CLS 0.1 以下、WCAG 2.2 AA の重大問題ゼロ
3. アクセス数・滞在・作品詳細ページへの到達率
4. ギャラリーサイトへの掲載、アワード受賞

問い合わせ件数は主目的に直結するが、母数が小さいため主要指標としては扱わない。

## 5. Design System v1 の利用範囲（最小）

計画の記述を採用。PF-07 以降の前提。

- 代表的な文章（見出し・本文・リード・キャプション）。日英両方の書体・行間・字間を含む
- 作品カード（Works 一覧）
- 音楽メディア（演奏メディアの埋め込み / プレイヤー）
- ナビゲーション、Contact 導線、言語切替

## 6. Design System v1 の完成条件

- [ ] 公開で使う共通部品の 100% にトークン・Figma・実装・Storybook の対応がある
- [ ] トークン変更 → 生成 → Figma 反映/差分確認 → 実装/Storybook → CI の検証手順を再現できる
- [ ] AI が既存部品と定義済みトークンで代表セクションを構築でき、型・基本 a11y 検査に合格する

## 7. 費用上限が DS の技術選定に与える制約

- Figma: 現行契約の範囲で運用。Variables / Code Connect の利用可否は PF-05 で契約条件を確認
- 配信: 無料プラン前提（Vercel Hobby / Cloudflare Pages など）。PF-04 で比較
- AI API: 従量課金に上限を設定。補助AI の試作（PF-06）は上限内で設計
- Storybook ホスティング: 無料枠（GitHub Pages / Chromatic 無料枠など）
