## 2. ブランド原則（5つ）

| # | 原則 | 内容 | 根拠 |
|---|---|---|---|
| 1 | 静かな基盤の上に、一つの主張 | 地色は無彩色に近い2色、アクセントは1色。面積は小さく、使う場所を決める | 参照DB 最多タグ「シンプル」426件。5つ星PF 6件中5件がアクセント1〜2色 |
| 2 | 文字と余白が主役 | 見出しは大きく締め、本文はゆったり。日英で同じリズム。装飾で埋めない | メモに「余白」「フォント選び」が頻出。現行本文行間1.8 |
| 3 | 動きは短く、意味があるときだけ | 200〜300ms、ease-out。ホバー・遷移は手触りのため | 「凝っているのに破綻しない」が高評価、「長すぎる」は減点。信念1 フィジカル |

| 5 | 仕組みが見える | DS自体が事例。トークンと部品の対応をサイト上で確かめられる | PF-01 成功指標1。Wise Design を「理想」と評価 |

## 3. 文章トーン

正本は `career/docs/voice-and-tone.md`（4特性: 丁寧で優しい / 親しみやすい / 理知的 / 明快、語尾を3回連続させない、1文30〜80字、断定は事実のみ）。サイト用の運用を以下に追加する。

| 場所 | トーン | 一人称 | 断定 | 英語 |
|---|---|---|---|---|
| Hero / About | セミフォーマル寄り。です・ます。冒頭の「こんにちは！」「Hey folks!」は許容 | 私 | 自己紹介と事実は断定、意見は柔らかく | I。短文。挨拶は許容 |
| Works 事例 | 事実と数字。1文1メッセージ | 省略可 | 成果は断定 | 数字は日英同精度 |
| Music | 同じ声で少し近く。問いかけ1つまで | 私 | 柔らかく | 同上 |
| Contact | 丁寧。「〜していただけますと幸いです」まで | 私、石川 | — | Thanks for reaching out. 程度 |
| 補助AI | AIであることを明示。答えられないときは原文へ案内 | このアシスタント | 推測を断定しない | 同上 |
| エラー・空状態 | 何が起きたか、次に何ができるか。謝らない、ふざけない | — | — | 同上 |

使わない: 素晴らしい / 最高の / 完璧な、「〜させていただく」の連打、「趣味は〜」で音楽を切り離す言い方。

## 4. 視覚の決め方（変更後）

ムードボード A「Score」/ B「Console」はどちらも採用しない（「すべて微妙」）。比喩から降ろすのではなく、トークンを工程順に一つずつ決め、都度確認する。

### 工程（本人提示の8工程 + 抜け補完 ★）

| # | 工程 | 出力 | 備考 |
|---|---|---|---|
| 0 ★ | トークンの構造と命名規則 | primitive → semantic → component の3層、DTCG形式、ファイル分割 | 本人判断で工程 6 の後に実施 |
| 1 | キーカラー設定 | 1色（OKLCH） | |
| 2 | キーカラーのスケール展開 | 50〜950 の11段 | 各段のコントラスト目標（白/黒に対する）を同時に定める |
| 3 | グレースケール展開 | 11段。キーカラー由来の色相バイアスを持たせるか決める | |
| 4 | サブカラーのスケール展開 | 装飾用サブ + ★ セマンティック用（success / warning / error / info） | サブの本数を先に決める |
| 5 | グレースケールのアルファ定義 | 白アルファ・黒アルファ各 8〜10段 | 境界線・オーバーレイ・ホバー面に使う |
| 6 | グラデーションシステム | 用途（背景 / 装飾 / 画像上）別に 2〜4 種 | 原則1 に反しない範囲。text に background-clip しない |
| 7 ★ | ライト / ダークのセマンティック割当 | surface / text / border / accent / state の役割トークンと、両テーマの primitive 対応表 | 本文 4.5:1、UI 3:1 をここで検証 |
| 8 | フォント決定 | 日本語・英語（・Mono の要否）、ライセンス、読み込み方法、サブセット | 費用上限 月3,000円の制約 |
| 9 ★ | ブレークポイントとコンテナ幅 | 3〜4 段 | 「デバイスごと」のタイプスケールの前提 |
| 10 | タイプスケールをデバイスごとに定義 | サイズ・行間・字間・ウェイト・役割名 | 日英混植の行間差、fluid の要否 |
| 11 ★ | スペーシングスケールと縦リズム | 4/8pt 基準、セクション余白 | タイプの行送りと連動 |
| 12 ★ | 角丸・線幅・影 / レイヤー | radius 3〜4段、stroke、elevation | 「全部カード」を避ける規則を含む |
| 13 ★ | モーショントークン | duration 3〜4段、easing 3種、reduced-motion 代替 | 原則3 |
| 14 ★ | 状態とフォーカス | hover / active / disabled / focus-visible の規則 | a11y 前提 |
| 15 ★ | ユーティリティ | アイコンサイズ、z-index、opacity | 部品実装時に必要 |

工程 0 と 7 は PF-09（トークン正本）の一部だが、色の判断を溜めないために PF-08 の中で先に決める。
